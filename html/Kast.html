This is a esp32 and raspberry pi powerd sorting system

It works using a CoreXY gantry that pushes the correct cabinet out of the closet. The interface is a Flask-based Python website built with HTML, CSS, and JavaScript, running locally on a Raspberry Pi. A database on the Raspberry Pi stores the location of each component. The ESP32 and Raspberry Pi communicate over Wi-Fi using an MQTT broker.

used items:

∙ Raspberry pi 4

∙ esp 32

∙ 2 steppermotors

∙ 2 A4988 stepper motor driver

∙ 9g servor motor

∙ 2 limit switches

∙ 2020 aluminium profiles
