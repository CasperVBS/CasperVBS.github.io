My alarm_clock

This was a project to learn the basics of pcb design. The clock is based on a Seeed Studio XIAO ESP32S3. It has 3 basic functions; showing the time, a timer and a stopwatch.

BOM (Bill Off Materials)

∙ 1x Seeed XIAO ESP32C3

∙ 4x MX-Style Keyboard Switches

∙ 4x White Blank DSA Keycaps

∙ 1x 2.25in TFT Screen

∙ 1x 3.3V Piezo Buzzer

∙ 1x 2.54mm 8 Pin Male Header

∙ 8x M3x5x4 Heatset Inserts

∙ 4x M3x8mm Screws

∙ 4x M3x16mm Screws
